## Описание
Training Planner — это GUI-приложение на Python для планирования тренировок.

Программа позволяет:
- Добавлять тренировки
- Сохранять данные в JSON
- Фильтровать тренировки
- Просматривать тренировки в таблице

## Возможности
- Добавление тренировок
- Фильтрация по типу тренировки
- Фильтрация по дате
- Сохранение и загрузка JSON
- Проверка корректности ввода

## Проверки
- Дата должна быть в формате YYYY-MM-DD
- Длительность должна быть положительным числом
- Пустые поля запрещены

## Использование
1. Запустите `main.py`
2. Заполните форму
3. Нажмите «Добавить тренировку»
4. Используйте фильтры для поиска
